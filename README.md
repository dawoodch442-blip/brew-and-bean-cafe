# Brew & Bean Cafe

A single-page website for a fictional cafe, built with HTML and CSS.

## Features
- Semantic HTML layout (header, nav, main, sections, footer)
- Sticky navigation bar with smooth scrolling
- Hero section with background image and gradient overlay
- Menu cards with shadows, hover effects and a "Best seller" badge
- Opening hours table with zebra rows
- Contact form with required fields
- Fixed back-to-top link
- Responsive layout

## Technologies
- HTML5
- CSS3

## How to run
Open `index.html` in any web browser.
